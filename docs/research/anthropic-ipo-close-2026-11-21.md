# Anthropic IPO 交割查核

- 台北 2026-11-21；本次交割公告日期為美東 2026-11-20。原文 `anthropic-ipo-pricing-2026.md` 保留 URL 與首次發布日。是同次發行完成與金額更新，不是另一筆募資。
- [公司交割公告](https://www.anthropic.com/news/ipo-close)：每股 83 美元，1,127,000,000 股，包括全數增額 147,000,000 股；公司售 1,103,351,354 股、原股東售 23,648,646 股。IPO 毛額 $93.5B、公司 IPO 毛額約 $91.6B、Class N 私募約 $26.0B，合計 $119.5B 含舊股且未扣費。公司沒取得舊股出售所得。第二日行情非本次更新。
